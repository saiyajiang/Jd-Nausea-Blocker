一个油猴脚本，按 **关键词 / 商品唯一编号 / 店铺** 屏蔽京东网页上让你感到不适的商品，可选「图片打码」或「彻底隐藏」。

## 这个脚本解决什么问题

刷京东的时候，首页推荐流和搜索结果里会混进一些让人不适的商品——人体骨骼标本模型、寄生虫/蟑螂特写图、撕拉鼻贴的面部放大照、脚气灰指甲、造口袋、血腥万圣节道具等等。

**京东官方没有提供关键词屏蔽功能**，你没法告诉它"别给我看这些"。这个脚本就是补上这个缺口：

> 你告诉它哪些词 / 哪些商品 / 哪些店铺不想看到，它就在页面里把这些商品卡**打码**或者直接**移除**，全程在你自己的浏览器里完成。

## 📦 什么是「商品唯一编号」？（重要）

京东给每一件商品分配一个**专属编号**，通常是一串数字，比如 `100012043978`。同一件商品的不同规格（颜色、容量、套装）各有各的编号。

> 电商行业里这个概念常被称为 **SKU**（Stock Keeping Unit，库存量单位）。为了不看懵，本脚本的界面和文档一律用中文「商品唯一编号」来称呼它。

**在哪能看到？** 打开任意京东商品页，看地址栏：

```
https://item.jd.com/100012043978.html
                    ↑↑↑↑↑↑↑↑↑↑↑↑
                    这串数字就是该商品的唯一编号
```

**为什么脚本要提供「按商品唯一编号拉黑」？** 对比一下三种规则的精度：

| 规则 | 精度 | 会误伤吗 |
| --- | --- | --- |
| **关键词** | 粗 | 会。屏蔽「蛇」会连蛇年文创、宠物蛇粮一起干掉 |
| **店铺** | 中 | 会。该店所有商品都消失，包括正常的 |
| **商品唯一编号** | **精确** | **不会。只屏蔽这一件商品** |

所以遇到"标题很正常、但图很恶心"的商品（关键词拦不住），**按商品唯一编号拉黑是唯一精准的解法**。鼠标悬停商品卡 → 点「屏蔽」→ 弹窗直接回车，脚本会自动读出该商品的唯一编号并加入黑名单。

> 严格说，京东里一件商品的不同规格（颜色、容量、套装）各有各的编号，它们归属于同一个商品聚合 ID（行业术语叫 SPU）。脚本两者都读取，够用了。

## 功能

| 能力 | 说明 |
| --- | --- |
| **两种屏蔽模式** | **图片打码**（默认）：商品仍在，图片被高斯模糊，鼠标悬停点「显示」可临时查看<br>**彻底隐藏**：商品卡直接消失 |
| **三类规则** | 关键词（支持正则，如 `/(腐烂\|腐尸\|血腥)/i`）、商品唯一编号黑名单、店铺黑名单 |
| **一键拉黑** | 鼠标悬停商品卡 → 右上角浮出「屏蔽 / 显示」按钮 → 点「屏蔽」可选：拉黑该商品的唯一编号 / 拉黑该店铺 / 顺手加关键词 |
| **改动即生效** | 设置面板里改关键词，停手 0.7 秒自动保存并重扫，不用手动点保存 |
| **覆盖页面** | 搜索页、列表页、首页推荐流、详情页推荐位（含商品链接的卡片都能识别） |
| **不闪图** | `document-start` 注入 + MutationObserver，卡片一进 DOM 就处理，不会先糊一张恶心图再消失 |
| **诊断工具** | 油猴菜单「🔍 诊断」显示：识别到几个商品卡、命中几个、前几个商品的真实标题 |
| **配置可迁移** | 设置面板「导出 / 导入」，纯 JSON，可同步到多台电脑 |

### 它是怎么认出商品卡的

京东隔段时间就改版，写死类名（比如 `li.gl-item`）很容易失效。所以脚本换了个思路：

1. 先抓页面上所有**商品链接**（`item.jd.com`、`/product/`、带 sku 参数）
2. 再从链接**反查**它属于哪张卡片：优先找带 `data-sku` / `data-spu` 的祖先 → 再看尺寸像个卡片的 `li` / `item` / `goods` 容器 → 最后退化到链接本身
3. 万一卡片还是认不出来，还有**图片级兜底**：只要某张图的 `alt` / `src` / `data-lazy-img` 命中关键词，就直接把那张图打码

这样即使京东改了具体类名，只要商品链接还在，脚本就还能工作。

## 怎么用

1. 安装后**打开京东并刷新页面**（装完脚本不刷新，当前页跑的还是旧代码）
2. 点油猴图标 →「⚙️ 设置」打开面板
3. 关键词一行一个，支持正则，例如 `/(腐烂|腐尸|血腥)/i`
4. 内置了一份默认关键词（标本 / 骨骼 / 寄生虫 / 蟑螂 / 腐烂 / 化脓 / 排泄物 / 痔疮等），**请按自己的接受度增删**

> 默认关键词**刻意没有收录**「蛇」「老鼠」「昆虫」这类词——容易误伤宠物用品、科普书籍。需要的话自己加。

**遇到标题正常、图很恶心的商品**：鼠标悬停卡片 → 点右上角「屏蔽」→ 弹窗直接回车 → 该商品的唯一编号进黑名单，精准消失。

## 常见问题

**改了配置没反应？**
先按 F5 刷新。然后点油猴菜单「🔍 诊断」，看「识别商品卡」这一行：

- 数字 > 0 且命中 > 0 → 正常工作
- 数字 = 0 → 京东又改版了，把诊断面板内容发到 [Issues](https://github.com/saiyajiang/Jd-Nausea-Blocker/issues)
- 数字正常但命中 0 → 标题没读到，诊断面板会列出真实标题，对着改关键词即可

**从旧版迁移后关键词没了？**
脚本身份由 `@namespace` + `@name` 决定，任一变化会被当成新脚本。**迁移前**在旧版面板点「导出」存好 JSON，**迁移后**点「导入」粘回。

**能不能同步到多台电脑？**
可以。设置面板的「导出 / 导入」按钮就是干这个的，配置是纯 JSON 字符串。

## 在 Greasyfork 上配置自动更新

1. 把本仓库推到 GitHub（分支 `main`，脚本路径保持 `jd-nausea-blocker.user.js`）
2. Greasyfork → 发布脚本 → 上传 `jd-nausea-blocker.user.js`
3. 脚本页面 →「管理」→ 勾选 **自动从 GitHub 更新**
   - 仓库：`saiyajiang/Jd-Nausea-Blocker`
   - 分支：`main`
   - 文件路径：`jd-nausea-blocker.user.js`
4. 保存。之后 Greasyfork 会定期抓取 `jd-nausea-blocker.meta.js` 比对版本

> 仓库里的 `.meta.js` 是给 Greasyfork 用的轻量元数据文件。它让 Greasyfork 只下载几十字节判断版本，版本没变就不重复拉取完整脚本。

## 发布新版本

```bash
# 1. 改代码
# 2. 改 jd-nausea-blocker.user.js 里的 @version（必须递增，Greasyfork 靠它判断更新）
# 3. 同步生成 meta.js
node update-meta.js

# 4. 提交
git add . && git commit -m "v2.2.0: 说明改了什么" && git push
```

Greasyfork 会自动同步，也可以在后台手动点「同步」。

⚠️ **`@version` 不变的话，Greasyfork 不会推送更新给用户**——这是最常见的"我改了但用户没更新"的原因。
